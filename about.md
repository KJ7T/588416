**Node:** 588416
**Callsign:** KJ7T
**Type:** Hub / link node — radio-free (no local RF, no physical repeater
attached)
**Network:** Runs on amateur radio's own 44Net (AMPRNet) address space,
rather than behind a conventional ISP connection.

Node 588416 is a dedicated AllStarLink hub used for linking and, more
recently, for experimenting with AI-assisted net logging (see
[The Transcription Project](transcription-project.md)). Because it has no
local radio hardware, all audio it carries arrives from — and is relayed
to — other linked nodes and repeaters.
