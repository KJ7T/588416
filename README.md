# 588416 Node Page

Off-node reference site for AllStarLink node 588416, published with GitHub
Pages using Jekyll's `minima` theme. GitHub builds this automatically from
the Markdown files on push — there is no local build or deploy step.

## Structure

- `_config.yml` — site settings and theme
- `index.md` — home page
- `about.md`, `disclaimers.md`, `transcription-project.md`, `changelog.md`
  — content pages, linked from the home page and the site nav

## Before publishing

- `disclaimers.md` and `changelog.md` are drafts — review and edit before
  this goes live.
- Add a real contact method to `index.md`.
- Once pushed, enable Pages in the repo's Settings → Pages, source:
  "Deploy from a branch," branch `main`, folder `/ (root)`.
